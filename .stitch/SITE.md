# Open Karaoke Mobile App Roadmap & Sitemap

## Site Vision
A high-performance mobile karaoke application featuring real-time pitch scoring, synchronized lyrics teleprompter, song catalog discovery, and personal score history/leaderboards.

## Project Metadata
- **Stitch Project ID**: `16394875771020119409`
- **Target Framework**: React Native (Expo) + NativeWind v4
